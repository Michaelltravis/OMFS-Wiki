# Proof-Point Examples — Track Record in Coastal and Complex Wastewater Systems

**Framing line:** "We have a demonstrated track record of improving wastewater system performance through disciplined operations and proactive problem solving. We have delivered similar results for comparable communities, including:"

**One-line reference format** (name/location generalized, one concrete accomplishment each):

- **[REFERENCE CLIENT — coastal New England community]:** Resiliency planning and a biosolids dewatering upgrade.
- **[REFERENCE CLIENT — Great Lakes/Upper Midwest regional utility authority]:** Stacked-tray grit removal system and a biosolids dewatering upgrade.
- **[REFERENCE CLIENT — Great Lakes/Upper Midwest community]:** Grant funding support and low-pressure collection system improvements.

**Expanded example 1 — reporting, odor, and efficiency turnaround:** At [REFERENCE CLIENT — New England community]'s WWTF and collection system, our team improved reporting transparency, reduced long-standing odor issues related to biosolids composting, and optimized chemical and power usage — enhancing system performance, community conditions, and operational efficiency.

**Expanded example 2 — odor control equipment upgrade with reliability and cost outcome:** For [REFERENCE CLIENT — coastal New England community]'s WWTP, Jacobs improved odor control by upgrading an aging biofilter system from organic media to engineered media with a significantly longer service life. This reduced replacement frequency, improved system reliability, and delivered over $134K in cost savings. This disciplined approach improves compliance stability, reduces variability, and supports predictable long-term operating costs.

## Reuse guidance

Universal: the one-line reference-list format (client descriptor + single concrete accomplishment) as a fast way to seed an executive summary's "track record" paragraph without needing a full past-performance write-up, and the two expanded-example patterns (transparency/odor/efficiency turnaround; equipment-upgrade-to-reliability-and-cost-outcome). Pursuit-specific: swap in real, currently-authorized reference projects relevant to the target client's own pain points (e.g., lead with the odor-control example for a client worried about odor complaints); never carry forward a prior pursuit's reference client name — this block intentionally omits it. The $134K cost-savings figure is an outcome/value figure from the actual reference project and is kept per current sanitization policy, but confirm it is still accurate and permissioned before reuse, and replace it with the correct figure if a different reference project is substituted.
