# Similar-Facilities Comparison Table — Framing & Format

A compact table (used as its own appendix) lists reference facilities selected specifically for their similarity to the target facility, ordered to emphasize relationship duration rather than facility size. It gives evaluators a fast, skimmable way to confirm direct relevance across a portfolio, complementing the narrative project descriptions elsewhere in the proposal.

## Column structure

| Column | Content |
|---|---|
| Client / Facility Name | Reference client and facility, hyperlinked to more detail if available elsewhere in the proposal |
| State/Region | Single field, sorted geographically to show national (or regional) footprint |
| Relationship Duration / Start Date | Both a duration ("40 Years, 10 Months") and a start date — duration alone is powerful, but the start date lets an evaluator sanity-check it |
| Processes Utilized | A dense, semicolon-separated list of unit processes across the full treatment train (disinfection, biosolids handling, odor control, effluent disposal method, secondary/tertiary treatment) — written to visually pattern-match against the target RFP's known process requirements |
| Capacity (MGD) | A single comparable number; combined facilities are noted as such |

## Selection logic

Reference facilities are chosen to demonstrate breadth across three dimensions simultaneously: (1) a range of relationship durations, weighted toward very long relationships (multiple entries exceeding 20–40 years) to establish durability; (2) a spread of capacities bracketing the target facility's size, including some notably larger and some comparable in scale; (3) process diversity that mirrors the target's actual or anticipated treatment train (e.g., membrane bioreactors, biosolids stabilization method, odor control technology, effluent reuse vs. discharge) so each row does double duty as both a longevity proof point and a technical-relevance proof point.

## Reuse guidance

Universal: the five-column structure and the "duration + process density" approach to proving relevance without narrative. Pursuit-specific: build the actual reference list from the firm's real, current O&M portfolio, filtered to facilities that genuinely match the target's capacity range and process types. The 5-row "representative pattern" table above is illustrative only and should not be reused as real references; the 13-row "full sanitized table" is the actual (sanitized) appendix content and can be mined for real process/duration/capacity data, but must be re-verified and updated against the firm's current portfolio before reuse in a live proposal — contract durations shown were accurate only as of this source proposal's date. Sort order (duration-first vs. capacity-first) should match whichever dimension is the stronger evaluation lever for the specific pursuit. Pair with the individual `project-narrative-*.md` blocks in this folder for any reference facility that also gets a full write-up elsewhere in the proposal.
