# How We'll Track, Measure, and Report Performance

Jacobs will implement an **integrated performance monitoring system that connects real-time operational data to the specific metrics** [CLIENT] — a regional water utility trust operating a multi-plant wastewater system — cares about most. Our approach combines three layers of oversight, illustrated in **Exhibit 1-4** (graphic asset ID 140_009385).

**Layer 1 — Real-time data dashboards.** Data dashboards provide real-time access to KPIs, including uptime, water quality compliance, production, odor monitoring, and maintenance performance. These dashboards have been successfully deployed for West Basin WMD, Woodland-Davis, and Twin Oaks in California; they deliver dynamic, on-demand visibility rather than a static monthly snapshot.

**Layer 2 — Independent QA/QC oversight.** Project Director Steve Carpenter and QA/QC Manager Josh Alleman will conduct internal audits of performance data, maintenance records, compliance tracking, and financial reporting. This independent review layer — sitting above day-to-day project management — identifies issues early and verifies that reported data accurately reflects field conditions.

**Layer 3 — Structured reporting against the performance metrics.**

- **Performance Requirements are continuously tracked in a compliance matrix by O&M teams.**
- **QA/QC Manager Josh verifies data accuracy prior to report submission.**
- **Monthly Payment Requests include complete, accurate, and defensible compliance reporting aligned with performance-based contract requirements.**

## Corrective Action and Escalation

When performance deviates from standards, our response will be immediate, documented, and traceable. Our process follows a structured escalation:

1. **Detection:** Real-time dashboards and daily operations monitoring flag deviations automatically.
2. **Root Cause Analysis:** Operations and maintenance staff investigate and document the cause within 24 hours.
3. **Corrective Action:** Project Manager/Operations Supervisor implements the fix and documents it in the CMMS.
4. **Verification:** QA/QC Manager verifies the corrective action closed the issue.
5. **Reporting:** Exception report provided to [CLIENT] with root cause, action taken, and prevention steps.

## Reuse guidance

Universal: the three-layer construct (automated detection → independent verification → structured reporting) and the five-step escalation with named role owners at each step. Both are drop-in for any performance-based O&M management plan.

Pursuit-specific: the named individuals, the reference dashboard deployments, the 24-hour root-cause window, and the payment-request tie-in — which only applies where self-reported compliance drives payment.
