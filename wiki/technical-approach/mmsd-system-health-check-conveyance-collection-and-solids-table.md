## Reuse guidance

Universal: the remedy vocabulary. Each row pairs an observable condition with a named tool or model, which is what lets a reviewer believe the diagnosis. The wet-weather row is the strongest reach-back proof in the section because it cites real reference projects (Tideway, Wilmington) rather than a capability claim.

Pursuit-specific and high sanitization loss: the findings belong to this district's conveyance system, and which facility carries which problem is proof value that generalization strips.
