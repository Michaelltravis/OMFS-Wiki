# CMMS Implementation Key Personnel and Mini-Resumes

## 3.3. Key personnel for CMMS implementation

The following Jacobs personnel will be involved in your NexGen implementation:

- **Eric Habermeyer, CMMS Implementation Project Manager** — Responsible for coordination with [CLIENT] and NexGen integration provider.
- **Janeane Giarusso, Sr. Asset Management Advisor** — NexGen implementation and partnering expertise.
- **Paul Miller, Asset Management Data Standards SME** — Consultant liaison for NexGen configuration and data standards.
- **Amy Dembinski, Integration Specialist** — Interface mapping and data validation.
- **John Loucks-Powell, O&M SME** — Operations and maintenance end user representative.

Additional Jacobs technical staff will work with [CLIENT]-dedicated administrators to support data migration, QA/QC, and dashboard development as the implementation schedule advances. Resumes for Eric Habermeyer, CMMS Implementation Project Manager, and John Loucks-Powell, Director of Maintenance and Asset Management, are provided in *Section II – Statement on Staffing, Training, and Corporate Culture*. Resumes for the remaining CMMS Implementation Key Personnel are provided at the end of this section.
