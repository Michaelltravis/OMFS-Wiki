# OSHG Experience Examples Table (Exhibit 3-4)

**Exhibit 3-4.** *Selected Examples of Jacobs' Experience with OSHG*

|FACILITY/CLIENT|SYSTEM TYPE/<br>MANUFACTURER|CAPACITY|DURATION<br>OF O&M|PROJECT FEATURES|

|**Pampa WWTP**<br>***City of Pampa, TX***|PSI MicroClor®|WWTP: 3 MGD<br>WTP: 5 MGD|Since 1985<br>(41 years)|We installed a chlorine alarm to notify appropriate authorities should there ever be a chlorine release. ## Reuse guidance

A drop-in exhibit for any pursuit involving on-site generation, disinfection chemistry, or advanced oxidation. The column set — facility/client, system type and manufacturer, capacity, duration of O&M, project features — is the reusable frame; write the Project Features cell to answer the specific risk the new client has raised about the technology rather than describing the equipment. Rows can be subset without weakening the exhibit.
